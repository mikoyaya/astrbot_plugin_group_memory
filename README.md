# QQ 群档案插件

这是一个面向 AstrBot QQ 群聊场景的轻量群档案与群记忆插件。

插件会在不主动回复、不调用 AI 的前提下，记录 QQ 群中的基础消息数据，为后续增加群成员备注、标签、画像、关系网和长期记忆功能准备可靠的数据基础。

## 当前能做什么

- 仅监听 QQ 群消息，不处理私聊消息。
- 支持 OneBot/aiocqhttp、QQ 官方机器人和 QQ 官方 Webhook 适配器。
- 自动记录群基础信息：平台实例、群号和可获取的群名称。
- 自动记录用户基础信息：平台实例、用户号和可获取的昵称。
- 自动保存消息纯文本、平台消息 ID 和消息时间。
- 同一平台实例下，相同消息 ID 只保存一次，避免重放消息造成重复记录。
- 支持毫秒级时间戳自动转换为 Unix 秒，保证按时间排序时保持一致。
- 启动时自动创建或检查 SQLite 数据库结构；缺失的基础表和索引会自动补齐。
- 提供群内状态命令：`/群档案状态`。

## 当前不会做什么

本版本专注于稳定记录基础数据，暂不包含以下功能：

- 不会主动私聊、主动搭讪或自动发言。
- 不会调用任何 AI 模型，也不会自动分析聊天内容。
- 没有 WebUI 页面、关系图或可视化界面。
- 没有成员备注、标签、画像、关系网和长期记忆的管理命令。

这些功能可以在后续版本基于现有数据库继续扩展，不影响已经保存的基础消息数据。

## 安装方式

### 方式一：放入 AstrBot 插件目录

1. 确认 AstrBot 已正常启动，并已配置至少一个 QQ 群聊适配器。
2. 将整个 `astrbot_plugin_group_memory` 文件夹放入 AstrBot 的插件目录：

   ```text
   AstrBot/data/plugins/astrbot_plugin_group_memory/
   ```

3. 确认插件目录内包含以下文件：

   ```text
   astrbot_plugin_group_memory/
   ├── metadata.yaml
   ├── _conf_schema.json
   ├── main.py
   ├── requirements.txt
   └── storage/
       ├── __init__.py
       └── database.py
   ```

4. 在 AstrBot WebUI 的插件管理中重新加载插件，或重启 AstrBot。
5. 在目标 QQ 群发送 `/群档案状态`，收到“SQLite 数据库已就绪”即可开始记录。

### 方式二：通过插件仓库安装

将本项目上传到 GitHub 后，可在 AstrBot 的插件安装界面填写 GitHub 仓库地址进行安装。仓库根目录必须直接包含 `metadata.yaml` 与 `main.py`，不要额外嵌套一层同名文件夹。

## 配置说明

插件加载后，可在 AstrBot WebUI 的插件配置中调整以下项目：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `listen_enabled` | `true` | 是否监听并记录 QQ 群消息。关闭后插件仍可加载，但不会新增消息记录。 |
| `database_filename` | `group_memory.db` | SQLite 数据库文件名。仅填写 `.db` 文件名，不要填写目录或绝对路径。 |

## 群内使用

在 QQ 群中发送：

```text
/群档案状态
```

当数据库可用时，插件会回复：

```text
QQ 群档案插件已启动，SQLite 数据库已就绪。
```

该命令只用于确认插件状态，不会展示群消息、成员资料或数据库内容。

## 数据记录规则

每条符合条件的 QQ 群消息会按照以下方式处理：

1. 确认消息包含群号、用户号和平台实例信息。
2. 不存在的群或用户会自动创建基础资料。
3. 保存消息的纯文本内容、消息时间和平台消息 ID。
4. 若相同平台实例已经记录过相同消息 ID，则该消息被判定为重复事件，不会再次入库，也不会覆盖已有群名或昵称。
5. 没有消息 ID 的消息仍会保存，但无法进行平台级去重。

用户资料当前以“平台实例 + 用户号”为唯一身份。同一个用户在不同群里的群名片可能不同；本版本只保留最近一次可取得的昵称。后续会通过独立的群成员资料表支持群内备注、群名片和标签。

## 数据库位置与隐私

数据库不会保存在插件代码目录中，而是保存在 AstrBot 数据目录：

```text
AstrBot/data/plugin_data/astrbot_plugin_group_memory/group_memory.db
```

数据库包含群号、用户号、昵称、消息纯文本和消息时间。请仅在已获得群管理者和成员授权的场景使用，并按所在地区的隐私与数据保护要求妥善保管、备份和清理数据。

卸载或更新插件时，请注意不要手动删除上述 `plugin_data` 目录，否则已有群档案数据将无法恢复。

## 常见检查步骤

如果插件没有记录消息，可按顺序检查：

1. AstrBot 插件管理页面中，插件是否已启用且没有加载错误。
2. QQ 适配器是否已连接，并且机器人已经在目标群内。
3. 是否为群聊消息，而不是私聊、频道或其他平台消息。
4. 插件配置中的 `listen_enabled` 是否为 `true`。
5. 发送 `/群档案状态` 是否显示数据库已就绪。
6. AstrBot 日志中是否出现数据库路径、权限或 SQLite 锁定相关错误。

## 技术说明

- 依赖：仅使用 Python 标准库 SQLite 与 AstrBot 插件 API，不额外引入第三方依赖。
- 数据库表：`plugin_metadata`、`groups`、`users`、`messages`。
- 数据库结构版本：当前为 v2，会在插件初始化时自动检查和补齐。
- 写入策略：SQLite 短暂繁忙时会进行有限重试；数据库写入在工作线程执行，尽量不影响 AstrBot 的消息处理流程。
